# Articulated rig experiment
This directory preserves the generated cut-out puppet, motion code, tests, prompts, and visual evidence.
It was explored as an articulated arrival, gesture, expression, and withdrawal system for Krishna Companion.
The owner parked this approach for M1; it is reference material for a human animator, not shipped code.
Rotating painted parts distorted anatomy, clothing, hands, and facial identity.
The prototype also lacked an animator-authored, keyframed gait, so its walk never felt natural.
The shipped companion instead uses the single original `assets/krishna.png` figure.
An animator can reuse the timing studies, pose vocabulary, generated sheets, and rejected-frame evidence here.
A production revival needs a consistent model sheet, separated clean artwork, fixed pivots, and turnarounds.
It also needs hand-keyframed gait, cloth overlap, gestures, expressions, transitions, and devotional review.
